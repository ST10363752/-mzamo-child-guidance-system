Frontend - Mzamo Child Guidance System

This folder contains the public website and administration portal for the Mzamo Child Guidance & Training Initiative of KZN.

Folder Structure

- `index.html` - Home page
- `about.html` - About Us page
- `services.html` - Services & Programmes page
- `news.html` - News & Updates page
- `contact.html` - Contact & Enquiry page
- `admin-login.html` - Admin login page
- `admin-dashboard.html` - Admin dashboard
- `admin-programmes.html` - Manage Programmes
- `admin-news.html` - Manage News
- `admin-reports.html` - Manage Reports
- `admin-enquiries.html` - Manage Enquiries
- `css/style.css` - Main stylesheet
- `js/` - JavaScript files
- `assets/` - Images and other assets
